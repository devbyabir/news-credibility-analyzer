# Reports

Generated by `python -m nca.train`. Committed so that results can be reviewed without rerunning.

| Folder | Config | Status |
|---|---|---|
| `robust/` | `configs/robust.json` (shortcut cues masked) | **Deployed model** |
| `baseline/` | `configs/baseline.json` (standard normalisation) | Reference only. Its top features are collection artifacts. |

Each folder contains:
- `data_audit.json` — row accounting and duplicate/conflict statistics (identical in both runs)
- `cv_folds.csv`, `cv_summary.csv` — grouped 5-fold CV on the training split (used for selection)
- `test_results.json` — every candidate's single held-out evaluation, calibration, bands, latency
- `model_metadata.json` — the metadata saved next to the model artifact
- `figures/` — confusion matrix, fake-class PR curve and reliability diagram (test split)
- `failure_cases.md`, `top_features.md` — the most confident errors and the most influential n-grams
- `train.log` — console output of the run

`robust/split_manifest.csv.gz` (row_id → train/test, with text hashes) and
`robust/excluded_rows.csv.gz` (row_id → exclusion reason) are byte-identical for both runs, so they
are stored only once.

`finetune_smoke.json` is a 4-step CPU debug run of `nca.finetune`. It proves the code path only;
its metrics are not a benchmark.
